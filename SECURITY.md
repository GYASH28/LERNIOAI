# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |
| `0.2.x` | Yes       |
| `< 0.2` | No        |

## Reporting a vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, report via GitHub Security Advisory:
<https://github.com/GYASH28/LERNIOAI/security/advisories/new>

Please include:
- A clear description of the vulnerability and its impact
- Steps to reproduce, including any proof-of-concept code
- Affected versions (commit SHA if possible)
- Suggested fix (if you have one)

## Response timeline

- Acknowledgement within **48 hours**
- Initial assessment within **5 business days**
- Critical vulnerabilities (CVSS ≥ 7.0) prioritised for fix within **7 days**

## Safe harbour

Good-faith security research is welcome. We will not take legal action against researchers who:
- Make a good-faith effort to avoid privacy violations and service interruption
- Do not access data other than their own
- Report vulnerabilities promptly via the channels above
